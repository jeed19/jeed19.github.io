1. プロ野球ペナントシミュレーター 作品概要

Javaで開発した、プロ野球のペナントレースをシミュレートするシステムです。単なるランダムな勝敗判定ではなく、選手個人の詳細なスタッツ、試合内の状況（カウント、ランナー）、さらには物理的な軌道計算や野手の反応速度ロジックなどを組み込み、精緻な試合展開を再現することを目指して開発しています。

開発言語 / 環境 Java (JDK 17)
主な技術要素 オブジェクト指向設計（各種デザインパターン）、ファイルI/O、物理シミュレーションロジック
開発体制・期間 個人開発 / 2026年2月 〜 現在継続中

2. 設計・クラス図

保守性と拡張性を高めるため、オブジェクト指向の原則に則った設計を行っています。役割ごとにクラスを明確に分離し、密結合を避ける設計を意識しました。

【ここにUMLクラス図の画像（PlantUMLなどで出力したもの）を配置】

設計におけるポイント

  • 堅牢なエラーハンドリング: 各種設定ファイルや選手データの読み込み時、不具合を未然に防ぐ「fail-fast（早期失敗）」の原則に基づき、厳格なバリデーションチェックを実装しています。
  • 柔軟な戦略の切り替え: 試合展開に応じた戦術変更ロジックには、デザインパターン（Strategyパターンなど）の適用を検討・配置し、コードの変更に強い構造にしています。

3. 主要ロジック・技術的こだわり

① 物理軌道と野手連動ロジック

打球のシミュレーションには、投球速度・打球角度・スピン量を考慮した「ホークアイ」ライクな軌道計算アルゴリズムを採用。さらに、野手ごとの守備位置、反応時間、移動速度（走力）をパラメータ化し、打球の到達点と野手の到達時間を比較してヒットか凡退かを判定するリアルなインターセプト判定を実装しました。

② ドラフト・選手育成ロジック

ペナントシミュレーターの醍醐味である「複数年の運用」に耐えうるよう、独自のドラフト思考アルゴリズムや経年劣化・急成長などの育成ロジックを搭載。各球団の補強ポイント（弱点ポジション）を自動解析し、最適な選手を指名するロジックを組んでいます。

        if (homeTeam.equals(awayTeam)) {
            throw new IllegalArgumentException("同一チームでの試合は設定できません。");
        }
        this.homeTeam = homeTeam;
        this.awayTeam = awayTeam;
    }

}
